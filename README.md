# Island Hopper Vanuatu

เกมผจญภัยพิกเซลสองภาษา (ไทย/อังกฤษ) เที่ยว 6 เกาะของวานูอาตูใน 15 วัน ตามหาชิ้นส่วนภาพวาดทรายของคุณตา Kalo

A bilingual (Thai/English) pixel-art adventure: hop across six islands of Vanuatu in 15 days and gather the pieces of Grandpa Kalo's sand drawing.

## เล่น / Play
เปิด `index.html` ในเบราว์เซอร์ หรือเล่นผ่าน GitHub Pages
Open `index.html` in a browser, or play it on GitHub Pages.

- ลูกศร / WASD: เดิน · Z / Enter: คุย, ตกลง · X / Shift: ย้อนกลับ, วิ่ง · M: สมุดเดินทาง
- On phones, use the on-screen buttons.

## เกาะ / Islands
Efate · Tanna · Espiritu Santo · Pentecost · Ambrym · Malekula

## พัฒนาต่อ / Development
ซอร์สแยกไฟล์อยู่ใน `src/` แก้แล้วรัน `sh src/build.sh` เพื่อสร้าง `index.html` ใหม่
Source parts live in `src/`. Edit them, then run `sh src/build.sh` to rebuild `index.html`.

ราคาและเวลาในเกมเป็นตัวเลขสมมติเพื่อการเล่น / Prices and opening times in the game are illustrative.
